# Production fonts

Full variable TTF fonts, not the small demonstration subsets. These cover every Japanese glyph in the imported common dictionary.

- Noto Sans JP: https://github.com/google/fonts/tree/main/ofl/notosansjp
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope

- IBM Plex Mono: https://github.com/google/fonts/tree/main/ofl/ibmplexmono
